🚀 Quick Start Guide

Get up and running in 5 minutes

1

Add the Discord Bot

Click the "Invite Bot to Discord" button on the home page. Select your server and authorize the bot.

Required Permission: You need Administrator permission in your Discord server to add bots.
2

Login with Discord

Click "Login with Discord" and authorize the application to access your Discord account information.

What we access: Your username, avatar, and server memberships/permissions.
3

Access Your Dashboard

Based on your Discord permissions, you'll be redirected to either:

  • Admin Dashboard - If you have Administrator permission
  • Moderator Panel - If you have Manage Members permission
4

Add Overlay to OBS

Copy the overlay URL from your dashboard and add it as a Browser Source in OBS Studio.

Recommended Settings:
Width: 1920 | Height: 1080 | FPS: 30
5

Start Controlling!

Use the moderator panel to update counters, messages, and trigger celebrations. Changes appear instantly on your OBS overlay!

🤖 Discord Bot Installation

Detailed instructions for adding the bot to your Discord server

Prerequisites

  • Discord account
  • Administrator permission in at least one Discord server
  • Modern web browser (Chrome, Firefox, Edge, Safari)

Installation Steps

1

Click the Invite Button

On the home page, locate the "Setup the Discord Bot" section and click the "Invite Bot to Discord" button.

2

Select Your Server

Discord will open an authorization page. From the dropdown menu, select the server where you want to add the bot.

⚠️ Important: Only servers where you have Administrator permission will appear in the list.
3

Review Permissions

The bot requests minimal permissions. Review and click "Authorize".

Permissions Requested: The bot only needs to be present in your server. It doesn't request any special permissions like managing roles or messages.
4

Complete CAPTCHA

Complete the "I'm not a robot" verification if prompted.

5

Verify Bot Presence

Return to your Discord server and verify the bot appears in the member list. You should see it online.

✅ Success! The bot is now installed and ready to authenticate users.

🔐 Authentication & Login

How the permission-based authentication system works

How Authentication Works

The Kill Feed System uses Discord OAuth for secure authentication. When you login, the system:

  1. Redirects you to Discord's authorization page
  2. You grant permission for the app to read your Discord profile and server memberships
  3. Discord returns you to the Kill Feed System with an authorization code
  4. The system exchanges this code for your user information
  5. Your permissions are checked across all servers where the bot is present
  6. You're redirected to the appropriate dashboard based on your highest permission level

Permission Levels

👑

Administrator Access

Discord Permission Required: Administrator

Access Level: Full system access

Features:

  • Admin Dashboard with system statistics
  • User management and monitoring
  • Complete configuration panel
  • All moderator controls
  • Activity logs and analytics
🎮

Moderator Access

Discord Permission Required: Manage Members (or higher)

Access Level: Control panel access

Features:

  • Moderator control panel
  • Counter management (increment/decrement/reset)
  • Scrolling message updates
  • Celebration triggers
  • Real-time overlay control

Multi-Server Support

How it works: If you have Administrator permission in any server where the bot is present, you get Admin access. The system checks all your servers and grants you the highest permission level found.

Session Duration

Once logged in, your session lasts for 7 days. After 7 days of inactivity, you'll need to login again. The session automatically extends with each visit.

📺 OBS Overlay Setup

Step-by-step guide to adding the overlay to OBS Studio

1

Open OBS Studio

Launch OBS Studio and navigate to the scene where you want to add the overlay.

2

Add Browser Source

In the Sources panel, click the + button and select "Browser" from the list.

3

Name Your Source

Give it a descriptive name like "Kill Feed Overlay" and click OK.

4

Get the Overlay URL

From your Dashboard or Moderator Panel, locate the "OBS Overlay URL" section and click the copy button.

Example URL: https://yourdomain.com/obs-overlay.html
5

Configure Browser Source

In the Browser Source properties window, paste the URL and configure these settings:

URL: [Paste your overlay URL]
Width: 1920
Height: 1080
FPS: 30
Shutdown source when not visible: ✓ Checked
Refresh browser when scene becomes active: ☐ Unchecked
6

Click OK

The overlay will appear in your scene. You can resize and reposition it as needed.

7

Test the Connection

Go to your Moderator Panel and click one of the counter buttons. The overlay in OBS should update immediately!

✅ It's Live! Your overlay is now connected and will update in real-time whenever changes are made in the control panel.

Troubleshooting OBS Issues

Overlay not showing?

  • Right-click the source and select "Interact" to see if there are any error messages
  • Verify the URL is correct (copy it again from the dashboard)
  • Try refreshing the browser source (right-click → Refresh)
  • Check your internet connection

Overlay not updating?

  • Check the connection status indicator in the moderator panel
  • Refresh the browser source in OBS
  • Verify your session is still active (login again if needed)
  • Check browser console for errors (right-click source → Interact → F12)

⚙️ Configuration Panel

Customize your overlay appearance and behavior

Accessing Configuration

The Configuration Panel is accessible from the Admin Dashboard. Navigate to Dashboard → Config Panel to customize your overlay.

Counter Configuration

Position Presets

Choose where counters appear on your overlay:

  • Top-Left: Upper left corner
  • Top-Center: Centered at the top
  • Top-Right: Upper right corner
  • Bottom-Left: Lower left corner
  • Bottom-Center: Centered at the bottom
  • Bottom-Right: Lower right corner

Layout Options

  • Horizontal: Counters arranged side-by-side in a row
  • Vertical: Counters stacked vertically
  • Grid: 2x2 grid layout (best for 3-4 counters)

Size Options

  • Small: Compact size, minimal screen space
  • Medium: Balanced size (recommended)
  • Large: Maximum visibility for viewers

Individual Counter Settings

For each counter (Kills, Extracted, KIA), you can customize:

  • Visibility: Show or hide the counter
  • Label: Custom text label (e.g., "Eliminations" instead of "Kills")
  • Icon: Any emoji (💀, ✅, ☠️, etc.)
  • Text Color: Color picker for label and value
  • Border Color: Color picker for counter border

Message Configuration

Position

  • Top: Scrolling bar at the top of the screen
  • Bottom: Scrolling bar at the bottom of the screen

Appearance

  • Font Size: Adjust text size (16px - 72px)
  • Text Color: Choose message text color
  • Border Color: Choose banner border color
  • Scroll Speed: Control how fast the message scrolls (1-50)

Enable/Disable

Toggle the scrolling message on or off without losing your configuration.

Celebration Configuration

General Settings

  • Enable Celebrations: Master toggle for all celebration effects
  • Duration: How long celebrations display (1-10 seconds)
  • Text Size: Size of celebration text (60px - 200px)
  • Effect Intensity: Particle density (Low/Normal/High)

Celebration Types

  • HURRAH: Golden fireworks with success text
  • RATS: Rat emojis falling from the sky
  • LUCK: Four-leaf clover emojis
  • FAIL: Poop emojis with failure text
  • HAMMER TIME: Shockwave effect with sound

Saving Configuration

Auto-Save: All configuration changes are saved automatically and apply immediately to all connected overlays. No need to refresh OBS!

🎮 Moderator Controls

How to use the moderator control panel

Counter Controls

Increment (+)

Click the + button next to any counter to increase its value by 1.

Decrement (-)

Click the - button next to any counter to decrease its value by 1.

Reset Individual Counter

Click the reset icon (🔄) next to a specific counter to set it back to 0.

Reset All Counters

Click the "Reset All Counters" button at the bottom to set all counters to 0 simultaneously.

Scrolling Message

Update Message

  1. Type your message in the text input field
  2. Click "Update Message" button
  3. Message will immediately start scrolling on the overlay

Show/Hide Message

Use the "Show Message" and "Hide Message" buttons to toggle the scrolling banner visibility without clearing the text.

Clear Message

Click "Clear Message" to remove the current message text and hide the banner.

Celebrations

Trigger Celebration

Click any of the celebration buttons to trigger an animation:

  • 🎉 HURRAH: For victories and achievements
  • 🐀 RATS: For unfortunate events
  • 🍀 GOOD LUCK: For risky plays
  • 💩 FAIL: For major failures
  • 🔨 HAMMER TIME: For epic moments

Celebrations play for the duration set in the configuration panel and automatically disappear.

Best Practices

  • Keep scrolling messages short and impactful
  • Use celebrations sparingly for maximum effect
  • Reset counters between gaming sessions for accuracy
  • Test changes during breaks to avoid stream interruptions

🔧 Troubleshooting

Common issues and solutions

Problem: Can't login / Keep getting redirected

Solutions:

  • Make sure the Discord bot is in your server
  • Verify you have Administrator or Manage Members permission
  • Clear your browser cookies and cache
  • Try a different browser or incognito mode
  • Check that you're logging in with the correct Discord account

Problem: Overlay not appearing in OBS

Solutions:

  • Verify the Browser Source URL is correct
  • Check Width (1920) and Height (1080) settings
  • Right-click source → Interact to check for errors
  • Try refreshing the browser source
  • Ensure your internet connection is stable

Problem: Changes not updating in real-time

Solutions:

  • Check connection status in moderator panel (green = connected)
  • Refresh the browser source in OBS
  • Verify your session hasn't expired (try logging in again)
  • Check server status and internet connection
  • Look for error messages in browser console (F12)

Problem: "Insufficient Permissions" error

Solutions:

  • Verify you have Administrator or Manage Members permission in your Discord server
  • Make sure the bot is present in the same server where you have permissions
  • Try re-inviting the bot to your server
  • Contact server owner to verify your role permissions

Problem: Session keeps expiring

Solutions:

  • Sessions last 7 days - login again if expired
  • Make sure cookies are enabled in your browser
  • Don't use incognito/private browsing mode
  • Check browser cookie settings allow third-party cookies

Still Having Issues?

If you're still experiencing problems:

  • Check the browser console (F12) for error messages
  • Verify server status at /health endpoint
  • Contact the system administrator
  • Report issues on the GitHub repository
